# Security policy

## Qo‘llab-quvvatlanadigan versiya

Hozircha faqat `main` va eng so‘nggi preview release security tuzatishlari oladi. `1.0` gacha API’da breaking change bo‘lishi mumkin.

## Muammo yuborish

Zaiflikni public issue’da yozmang. GitHub’dagi [private security advisory](https://github.com/uzbekona-dev/telekit/security/advisories/new) orqali reproduksiya, ta’sir doirasi va mumkin bo‘lsa patch taklifini yuboring.

Bot tokeni, `APP_KEY`, real callback payload yoki foydalanuvchi ma’lumotini report’ga qo‘shmang. Qabul qilingan report’ga imkon qadar 72 soat ichida dastlabki javob berish maqsad qilinadi.
